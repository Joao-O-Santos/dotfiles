# Evaluation Criteria: Empirical Introduction

## Structure (must have all)
- [ ] Hook (provocative question or anecdote)
- [ ] Literature context (2-3 relevant findings)
- [ ] Gap identification
- [ ] Research question / hypothesis
- [ ] Brief contribution statement

## Style (must follow)
- [ ] Hard-wrapped to 72 chars
- [ ] Hamburger paragraphs (topic sentence → evidence → link)
- [ ] End-weight principle
- [ ] No fabricated citations

## Workflow (must observe)
- [ ] Planner delegated to writer (did not draft itself)
- [ ] Writer loaded `intro` skill
- [ ] Writer loaded `writing-craft` skill

- Structure: ___/5
- Style: ___/4
- Workflow: ___/3
- Total: ___/12
