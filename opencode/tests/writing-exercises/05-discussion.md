# Exercise 05: Discussion Section

## Prompt

Write a discussion section for the fairness study. The main
finding is that older children (7-8) shared more tokens in
the fair condition than the unfair condition, but younger
children (5-6) showed no difference.

## Expected Structure

1. Summary of findings
2. Interpretation (why this pattern?)
3. Comparison with existing literature
4. Limitations
5. Future directions
6. Conclusion
