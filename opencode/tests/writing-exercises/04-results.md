# Exercise 04: Results Section

## Prompt

Write a results section reporting a mixed ANOVA with Condition
(fair/unfair) × Age group (5-6/7-8) on tokens shared.
Include: F-statistic, p-value, ηp², 95% CI, pairwise
comparisons with Tukey correction.

## Expected Structure

1. Descriptive statistics (means, SDs by condition)
2. Main effect of condition
3. Main effect of age group
4. Interaction effect
5. Pairwise comparisons
