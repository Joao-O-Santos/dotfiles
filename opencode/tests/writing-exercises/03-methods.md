# Exercise 03: Methods Section

## Prompt

Write a methods section for a study investigating children's
perceptions of fairness using a resource-allocation task.
80 children aged 5-8, between-participants design (fair vs
unfair condition), DV: number of tokens shared.

## Expected Structure

1. Participants (demographics, recruitment, exclusion criteria)
2. Materials (task description, stimuli)
3. Procedure (order of events, instructions)
4. Analysis plan (statistical approach)
