# Exercise 06: Abstract

## Prompt

Write a 150-word abstract for the fairness study. Structured
format: Background, Methods, Results, Conclusion.

## Expected Structure

1. Background (1-2 sentences)
2. Methods (1-2 sentences)
3. Results (1-2 sentences)
4. Conclusion (1 sentence)

## Measurable Metrics

| Metric | How to measure | Target |
|--------|---------------|--------|
| Word count | Count words in abstract | 140-160 |
| Time to first draft | Clock from prompt to writer output | ___ min |
| Fix iterations | Count of writer invocations | ≤ 2 |

## Manual Metrics

| Criterion | Check |
|-----------|-------|
| Covers all sections | Background, Methods, Results, Conclusion? |
| Within word limit | 140-160 words? |
| Standalone readable | Makes sense without the full paper? |
| No citations | Abstract should be citation-free? |
| Loads `abstract` skill | Did the writer load the right skill? |
