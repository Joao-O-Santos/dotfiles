# Theoretical / Review Paper Routing

For theoretical, perspective, or review papers (no empirical data):

**DO NOT load:** `methods`, `results`
**DO load:** `intro` (use theoretical hook patterns — see intro skill
  §Theoretical Papers), `discussion` (use theoretical structure only —
  skip the empirical "Recap patterns" section, see discussion skill
  §Theoretical Papers), `title`, `abstract`, `lit-review-section`,
  `apa7-refs`, `writing-craft`, `manuscript-workflow`

The `discussion` skill has separate empirical and theoretical
structures. When loading for a theoretical paper, use only the
§Theoretical Papers path: synthesize arguments, implications,
limitations, future directions. Skip §Empirical Papers entirely.

The `intro` skill has theoretical hook patterns — use those, not
empirical hooks. The empirical hooks assume data/experiments.

For mixed papers (empirical with substantial theory section): load
all skills but use the theoretical structure for the theory portions.
